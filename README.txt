My Report Archive
=================

これは、論文形式レポートのPDFを整理・閲覧するためのWebページです。
ログイン画面でパスワードを確認し、ログイン後だけ一覧・PDF・追加フォームにアクセスできます。

ローカルで使う
--------------
1. ターミナルでこのフォルダに移動する。
2. REPORT_PASSWORD="好きなパスワード" node server.js を実行する。
3. ブラウザで http://127.0.0.1:3000 を開く。
4. パスワードを入力して開く。

一時公開URLを作る
----------------
start-public.command をダブルクリックすると、ローカルサーバーと Cloudflare Tunnel をまとめて起動します。
起動時にログイン用パスワードと削除専用パスワードを入力してください。
表示された trycloudflare.com のURLが一時公開URLです。

公開を止める
------------
stop-public.command をダブルクリックすると、公開トンネルとローカルサーバーを停止します。

公開サイトとして使う
------------------
公開サービスでは、環境変数を設定してください。

REPORT_PASSWORD: ログイン用パスワード
DELETE_PASSWORD: 削除専用パスワード
SESSION_SECRET: Cookie署名用の長いランダム文字列
HOST: 0.0.0.0
PORT: 公開サービスが指定するポート

重要
----
PDFを追加すると、ファイルは uploads フォルダに保存され、一覧データは data/papers.json に保存されます。
公開する場合は、REPORT_PASSWORD を必ず変更してください。未設定の場合は仮パスワード change-me で起動します。
削除機能を使う場合は、DELETE_PASSWORD も必ず設定してください。未設定の場合、削除は無効です。
